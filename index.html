Built for Every Distro, DE, and Init

IdleScreen is engineered from the metal up in Rust to integrate natively across the entire modern Linux landscape without runtime bloat or desktop-specific lock-in.

[ 01 // HOST OS ]

Supported Distributions

Autonomous multi-probe detection with zero external dependencies via /etc/os-release, /etc/lsb-release, /etc/issue, and kernel uname(2).

● Fedora / RHEL ● Debian / Ubuntu ● Arch / Endeavour / CachyOS ● Alpine Linux ● openSUSE ● Void Linux ● Gentoo
DETECTION: Multi-probe hierarchy (os-release, lsb, uname)
[ 02 // COMPOSITORS & DESKTOPS ]

Wayland & Compositors

Native Wayland surface overlay and per-output refresh rate matching over layer-shell, yielding instantly on the first human keystroke or pointer event.

● GNOME (Mutter IdleMonitor) ● KDE Plasma (KWin) ● COSMIC (cosmic-comp) ● Hyprland ● Sway ● Wayfire ● River ● Labwc
PROTOCOLS: wlr-layer-shell & ext-idle-notify-v1
[ 03 // INIT & SUPERVISORS ]

All Init Systems

Runs under any supervision architecture with zero-timeout D-Bus activation, clean SIGTERM dispatch, and zero CPU usage while the user is actively working.

● systemd (user service + D-Bus) ● OpenRC ● runit ● dinit ● s6 ● Standalone supervisor loop
D-BUS: org.freedesktop.ScreenSaver zero-timeout activation
