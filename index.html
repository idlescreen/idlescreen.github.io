Package Repository Setup

Manual installation steps for your package manager

# Step 1: Add DNF Repository
sudo curl -fsSL https://idlescreen.github.io/packages/rpm/idlescreen.repo -o /etc/yum.repos.d/idlescreen.repo

# Step 2: Install idlescreen
sudo dnf check-update
sudo dnf install idlescreen

# Launch:
idlescreen tui
# Step 1: Add GPG Key & Repository
sudo mkdir -p /etc/apt/keyrings
curl -fsSL https://idlescreen.github.io/packages/apt/idlescreen-keyring.gpg | sudo tee /etc/apt/keyrings/idlescreen-keyring.gpg >/dev/null
echo "deb [signed-by=/etc/apt/keyrings/idlescreen-keyring.gpg] https://idlescreen.github.io/packages/apt stable main" | sudo tee /etc/apt/sources.list.d/idlescreen.list >/dev/null

# Step 2: Install idlescreen
sudo apt update
sudo apt install idlescreen

# Launch:
idlescreen tui
# Step 1: Clone Package Definitions
git clone https://github.com/idlescreen/packages.git
cd packages/arch

# Step 2: Build & Install
makepkg -si
IDLESTUDIO SDK

Build & Render Custom Screensavers

Create WGPU shaders, batch video queues, and offline AV1 renders with IdleStudio.

# Enqueue offline video render job:
idle-studio enqueue -e beams -o /tmp/beams_4k.mkv --duration 8h --segment 1h --resolution 4k

# List pending render jobs in queue:
idle-studio list

# Process all queued render jobs:
idle-studio run --all
# Launch interactive batch queue TUI:
idle-studio tui

# TUI Keyboard Shortcuts:
# j / k Move selection up / down
# r Run next pending render job
# a Run all pending render jobs in queue
# R Reload job queue from disk
# q Quit TUI
