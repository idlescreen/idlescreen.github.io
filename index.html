Ambient by Design_

IdleScreen watches compositor idle signals over ext-idle-notify-v1 (and GNOME Mutter IdleMonitor), launches lightweight graphics onto wlr-layer-shell surfaces across every monitor, and yields the instant you touch the keyboard. Powered by a high-performance in-tree ASCII screensaver engine featuring 37 standalone scenes, dynamic in-tree ASCII tri-rotation between Host OS, Desktop Environment, and Linux Kernel, dynamic 60–144 Hz monitor refresh rate matching, and responsive 400% multi-cell font scaling.

UNIVERSAL LINUX COMPATIBILITY // ZERO-OVERHEAD DISPATCH

Built for Every Distro, DE, and Init

IdleScreen is engineered from the metal up in Rust to integrate natively across the entire modern Linux landscape without runtime bloat or desktop-specific lock-in.

[ 01 // HOST OS ]

Supported Distributions

Autonomous multi-probe detection with zero external dependencies via /etc/os-release, /etc/lsb-release, /etc/issue, and kernel uname(2).

● Fedora / RHEL ● Debian / Ubuntu ● Arch Linux / EndeavourOS / CachyOS ● Alpine Linux ● openSUSE ● Void Linux ● Gentoo
DETECTION: Multi-probe hierarchy (os-release, lsb, uname)
[ 02 // COMPOSITORS & DESKTOPS ]

Wayland & Compositors

Native Wayland surface overlay and per-output refresh rate matching over layer-shell, yielding instantly on the first human keystroke or pointer event.

● GNOME (Mutter) ● KDE Plasma (KWin) ● COSMIC (cosmic-comp) ● Hyprland ● Sway ● Wayfire ● River ● Labwc
PROTOCOLS: wlr-layer-shell & ext-idle-notify-v1
[ 03 // INIT & SUPERVISORS ]

All Init Systems

Runs under any supervision architecture with zero-timeout D-Bus activation, clean SIGTERM dispatch, and zero CPU usage while the user is actively working.

● systemd (user service with zero-timeout D-Bus activation) ● OpenRC ● runit ● dinit ● s6 ● Standalone supervisor loop
D-BUS: org.freedesktop.ScreenSaver zero-timeout activation

DEPLOYMENT // PACKAGES & VERIFICATION

Installation & Package Channels

Be up and running in seconds. Available via standalone shell installer, native package repositories, or Rust Cargo.

[ 01 // RECOMMENDED ]

Automated Shell Installer

Auto-detects your architecture, distribution, and init system. Installs binary to ~/.local/bin, configures systemd user service if present, and sets up man pages.

curl -fsSL https://idlescreen.github.io/install.sh | sh
VERIFY: Cryptographic SHA-256 integrity verification
curl -fsSL https://idlescreen.github.io/install.sh | sh -s -- --verify
[ 02 // DISTRO PACKAGES ]

Native Package Channels

Pre-built packages maintained across major distributions with automatic updates.

FEDORA / RHEL (COPR)
sudo dnf copr enable idlescreen/idlescreen && sudo dnf install idlescreen
ARCH LINUX (PACMAN / AUR)
sudo pacman -S idlescreen # or paru / yay -S idlescreen
DEBIAN / UBUNTU (APT)
sudo apt install idlescreen
ALPINE LINUX (APK)
apk add idlescreen
[ 03 // RUST TOOLCHAIN ]

Build from Source

Compile from source with native SIMD acceleration directly using the Cargo toolchain.

cargo install idlescreen

Or build directly from the GitHub monorepo:

git clone https://github.com/idlescreen/idlescreen && cd idlescreen && cargo build --release
[ 04 // QUICK START & VERIFY ]

Daemon Management

Essential commands to control the idle daemon, verify integrity, and explore in-tree scenes.

ENABLE & START DAEMON (SYSTEMD)
systemctl --user enable --now idlescreen
PREVIEW SPECIFIC SCENE
idlescreen preview fireworks
LIST ALL 37 IN-TREE SCENES
idlescreen list --scenes
VERIFY INTEGRITY & DIAGNOSTICS
idlescreen --verify
