Ambient by Design

Modular Wayland idle host and procedural screensaver plugins for Linux. Watches compositor idle signals over ext-idle-notifier-v1, launches lightweight graphics onto layer-shell surfaces across multi-monitor outputs, and yields compute back instantaneously on user input. Plugins expose a stable C ABI — write a saver in any language that compiles to a shared library.
