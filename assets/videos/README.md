# Screensaver Media Directory

Drop your screensaver `.mp4` video recordings or `.gif` animation files into this directory!

### Recommended Filenames:
- `beams.mp4` / `beams.gif`
- `cosmos.mp4` / `cosmos.gif`
- `bursts.mp4` / `bursts.gif`
- `storm.mp4` / `storm.gif`
- `chaos.mp4` / `chaos.gif`
- `hearth.mp4` / `hearth.gif`
- `ripple.mp4` / `ripple.gif`
- `radar.mp4` / `radar.gif`
- `glyphs.mp4` / `glyphs.gif`
- `gnats.mp4` / `gnats.gif`

The homepage (`index.html`) automatically loads and loops any video or gif matching these filenames!
