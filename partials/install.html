Installation & Package Channels

Be up and running in seconds. Available via standalone shell installer, native package repositories, or Rust Cargo.

PAUSE ON HOVER • CLICK [ COPY ] TO CLIPBOARD
[ 01 // RECOMMENDED ]

Automated Shell Installer

Auto-detects your architecture, distribution, and init system. Installs binary to ~/.local/bin, configures systemd user service if present, and sets up man pages.

curl -fsSL https://idlescreen.github.io/install.sh | sh
VERIFY: Cryptographic SHA-256 integrity verification
curl -fsSL https://idlescreen.github.io/install.sh | sh -s -- --verify
[ 02 // DISTRO PACKAGES ]

Native Package Channels

Pre-built packages maintained across major distributions with automatic updates.

FEDORA / RHEL (COPR)
sudo dnf copr enable idlescreen/idlescreen && sudo dnf install idlescreen
ARCH LINUX (PACMAN / AUR)
sudo pacman -S idlescreen # or paru / yay -S idlescreen
DEBIAN / UBUNTU (APT)
sudo apt install idlescreen
ALPINE LINUX (APK)
apk add idlescreen
[ 03 // RUST TOOLCHAIN ]

Build from Source

Compile from source with native SIMD acceleration directly using the Cargo toolchain.

cargo install idlescreen

Or build directly from the GitHub monorepo:

git clone https://github.com/idlescreen/idlescreen && cd idlescreen && cargo build --release
[ 04 // QUICK START & VERIFY ]

Daemon Management

Essential commands to control the idle daemon, verify integrity, and explore in-tree scenes.

INTERACTIVE DASHBOARD (TUI)
idlescreen tui
PREVIEW SPECIFIC SCENE
idlescreen preview ascii
ENABLE & START DAEMON (SYSTEMD)
systemctl --user enable --now idlescreen
LIST ALL 37 IN-TREE SCENES
idlescreen list --scenes
VERIFY INTEGRITY & DIAGNOSTICS
idlescreen --verify
