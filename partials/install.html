Installation & Package Channels

Be up and running in seconds. Available via standalone shell installer, native package repositories, or Rust Cargo.

PAUSE ON HOVER • CLICK [ COPY ] TO CLIPBOARD
[ 01 // RECOMMENDED ]

Automated Shell Installer

Auto-detects your distribution (including first-class SuperFedora), Wayland compositor, and init system. Configures signed package repositories, preserves config.toml, and enables user supervision.

curl -fsSL https://idlescreen.github.io/install.sh | sh
VERIFY: Cryptographic SHA-256 integrity verification
curl -fsSL https://idlescreen.github.io/install.sh | sh -s -- --verify
[ 02 // DISTRO PACKAGES ]

Native Package Channels

Signed unified idlescreen package with all 50 built-in 16-bit arcade & mathematical scenes included out of the box.

SUPERFEDORA / FEDORA / RHEL (DNF)
sudo dnf install idlescreen
ARCH LINUX / CACHYOS (PACMAN)
sudo pacman -S idlescreen
DEBIAN / UBUNTU / POP!_OS (APT)
sudo apt install idlescreen
ALPINE LINUX (APK)
apk add idlescreen
[ 03 // HARDWARE-TUNED SOURCE ]

Build from Source

Compile from source with native CPU SIMD acceleration (target-cpu=native) and LTO using the Rust toolchain.

RUSTFLAGS="-C target-cpu=native" cargo build --release --workspace

Clone and build the full workspace from the GitHub monorepo:

git clone https://github.com/idlescreen/idlescreen && cd idlescreen && cargo build --release --workspace
[ 04 // CLI & DIAGNOSTICS ]

Daemon Management

Control the idle daemon, tour new 16-bit arcade scenes, provision any init system, inspect inhibitors, and auto-remediate issues.

INTERACTIVE DASHBOARD (TUI)
idlescreen tui
TOUR THE 13 NEW 16-BIT ARCADE SCENES
idlescreen preview --tour
DIAGNOSTICS & AUTO-REMEDIATION
idlescreen doctor --fix
INSPECT ACTIVE IDLE INHIBITORS
idlescreen inhibitors
LIST ALL 50 BUILT-IN 16-BIT ARCADE SCENES
idlescreen list
