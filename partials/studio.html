OFFLINE SAVER RENDERING // STUDIO

IdleScreen Studio

Render the screensaver to video, offline. Studio links the daemon's rendering core and runs the same 53 scenes the screensaver draws on screen, frame by frame, straight into ffmpeg — no Wayland session, no compositor, no display attached. idle-studio is the Director TUI for queueing and tuning export jobs.

[ 01 // RECOMMENDED ]

Install Studio

One command installs the render engine and the Director TUI from the same signed channel as the daemon. The signing key's fingerprint is pinned out-of-band, every helper module is verified against a pinned SHA-256, and the repo file is written from pinned content — never fetched.

curl -fsSL https://idlescreen.github.io/packages/install-studio.sh | sh
PACKAGES idle-studio · render
CHANNEL gpgcheck=1 · repo gpgcheck=1
REMOVE install.sh | sh -s -- --uninstall
[ 02 // HEADLESS RENDER ]

Render a Saver

One command, one file. The engine runs the scene and encodes it through ffmpeg — nothing to clean up afterwards, and the same scene, text and seed always produce the same bytes.

render -e beams --duration 10s -o ~/Videos/beams.mkv
DURATION 10s · 5m · 2h · 1d
FORMAT AV1 (mkv) · H.264 (mp4) · PNG · raw
SIZE --width / --height
REPEATABLE same seed → same bytes
[ 03 // DIRECTOR TUI ]

Queue & Tune Jobs

Prefer a terminal to a command line? idle-studio is a Director for export jobs: pick the scene and the words it animates, set duration, resolution, fps and quality, then queue, pause and run them.

idle-studio
SCENES 53 built in — aurora · beams · binarypath · …
TUNING duration · width · height · fps · crf
DRY RUN toggle before you commit

Studio is a separate product from the daemon: it renders saver loops to files and never takes over your screen. It drives the daemon's own scene code, so an export is a clean, reproducible loop of the very same scenes — not a screen recording of your live session. Source ↗
