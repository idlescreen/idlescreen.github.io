Rust (v4.8.2) vs. Native openOODA (v5.0.0)

IdleScreen was rebuilt 1:1 from Rust (main branch, v4.8.2) into native openOODA (.oo) (ooda branch, v5.0.0). Same 53 built-in scenes, same CLI/TUI workflow, and 18/18 bit-exact golden scene parity — at 14× smaller binary size, zero external dependencies, and a flat 2.62 MiB 1,000-frame resident footprint.

[ IDLESCREEN v5.0.0 // OPENOODA (ooda) ]

339 KB Binary • 2.62 MiB Flat RSS

  • ✓
    14× Smaller Binary & 11× Smaller Package: 339 KB single Linux ELF (133 KB RPM / 115 KB DEB, 1.4 MB total installed) + 1.5 MB native Windows PE32+ (idlescreen.exe).
  • ✓
    Zero External Dependencies: 100% self-contained .oo + oostd across 35 modular pages obeying the strict 1/2/4/8/16/32/64/128/256 power-of-2 shape ladder.
  • ✓
    2.62 MiB Flat 1,000-Frame Peak RSS: Per-frame OODA arena mark/reset reclamation (@oo_arena_mark / @oo_arena_reset_mark) sustains 2,688 KB RSS across 1,000 frames of blackhole with zero heap growth.
  • ✓
    Default-Deny 64-Bit Capabilities: Explicit CAP_FS_READ and CAP_STDIO capability tokens attenuated before entering the render loop; zero unsafe blocks.
  • ✓
    18/18 Bit-Exact Golden Parity: Deterministic SplitMix64 PRNG and integer trig LUTs pass make det && make parity with byte-identical builds and 18/18 golden scene verification.
