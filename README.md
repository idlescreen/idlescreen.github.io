# idlescreen.github.io

The product site — landing page, saver showcase, and the documented
install entry point. Part of
[IdleScreen](https://idlescreen.github.io) — modular Wayland screensavers
for Linux.

## Install

Visit <https://idlescreen.github.io>. The install command surfaces the
[`packages`](https://github.com/idlescreen/packages) channel:

```sh
curl -fsSL https://idlescreen.github.io/packages/install.sh | sh
```
